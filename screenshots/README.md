# Postman Teslim Ekran Görüntüleri

Postman'de TASKFLOW CRUD koleksiyonunu çalıştırdıktan sonra kendi test sonuç ekran görüntülerini bu klasöre ekle.

Önerilen kanıtlar:
- Görev oluşturma isteği ve 201 yanıtı
- Görev listesi ve görev detayı yanıtları
- Görev güncelleme ve silme yanıtları
- Koleksiyon Runner özeti
